# 🎓 Projet Laravel 12 LTS - Application Fullstack

Ce projet utilise **Laravel 12 LTS** pour le développement back-end avec un front-end basé sur **Blade** et **Bootstrap**. Il combine **MySQL** pour les données relationnelles et **MongoDB** pour les données non structurées (avis, consultations).

---

## 📦 Technologies utilisées

### 🔙 Back-end

- **Laravel 12 LTS** – Framework PHP moderne, robuste, basé sur MVC.
- **MySQL** – Base de données relationnelle.
- **MongoDB** – Stockage NoSQL pour les données non structurées (avis, consultations).
- **Mailjet** – Envoi d’emails fiables (formulaire de contact, retours clients).

### 🎨 Front-end

- **Blade** – Moteur de templates Laravel (HTML + PHP).
- **Bootstrap** – Framework CSS responsive.
- **JavaScript** – Interactions sans rechargement de page.

### 🚀 Déploiement

- **Heroku** – Hébergement cloud avec intégration Git.
- **GitHub** – Gestion des versions en branches.
- **Docker (optionnel)** – Pour rendre le projet portable et reproductible.

### 🧰 Outils de développement

- **Visual Studio Code** – Éditeur avec extensions PHP, Blade, Git, MongoDB.
- **XAMPP** – Serveur local Apache + MySQL + phpMyAdmin.
- **phpMyAdmin** – Interface pour gérer MySQL localement.
